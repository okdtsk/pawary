# Careteam Log Notifications Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Notify the other careteam members of a pet, via web push, when a member adds a new activity — coalesced over a 60s window, with a per-user opt-out.

**Architecture:** A per-pet `CareteamNotifier` Durable Object debounces with a fixed 60s alarm. The activity-create handler fires a `ping` (via `waitUntil`); on alarm the DO queries D1 for activities since a stored watermark, resolves recipients (members minus authors, opted-in, with push subscriptions), and fans out localized pushes reusing the existing web-push sender. A new `users.notifyCareteamLogs` boolean backs the opt-out, surfaced as a toggle in the existing Notifications card. The notification deep-links to `/log?pet=<petId>`.

**Tech Stack:** Cloudflare Workers + Durable Objects (SQLite-backed), Hono, Drizzle/D1, React + TanStack Query, Vitest (`@cloudflare/vitest-pool-workers`).

**Spec:** `docs/superpowers/specs/2026-06-14-careteam-log-notifications-design.md`

import type { Category } from "@pawary/shared";
import { categoryLabel } from "./labels";

type Locale = "en" | "ja";

function resolveLocale(locale: string | null | undefined): Locale {
  return locale === "ja" ? "ja" : "en";
}

/** Human-readable author list. JA always carries the さん honorific. */
export function formatAuthors(names: string[], locale: string): string {
  const first = names[0] ?? "";
  if (resolveLocale(locale) === "ja") {
    if (names.length <= 1) return `${first}さん`;
    if (names.length === 2) return `${first}さんと${names[1]}さん`;
    return `${first}さん他${names.length - 1}人`;
  }
  if (names.length <= 1) return first;
  if (names.length === 2) return `${first} & ${names[1]}`;
  return `${first} & ${names.length - 1} others`;
}

/**
 * Build the `{title, body, url}` push payload for one recipient.
 * `category` is set only for the single-item case; multi-item bodies use a count.
 */
export function buildNewLogPayload(opts: {
  petName: string;
  petId: string;
  authorNames: string[];
  itemCount: number;
  category: Category | null;
  locale: string;
}): string {
  const loc = resolveLocale(opts.locale);
  const who = formatAuthors(opts.authorNames, opts.locale);
  let body: string;
  if (opts.itemCount === 1 && opts.category) {
    const cat = categoryLabel(opts.category, opts.locale);
    body = loc === "ja" ? `${who}が${cat}を記録しました` : `${who} logged ${cat}`;
  } else {
    body =
      loc === "ja"
        ? `${who}が${opts.itemCount}件記録しました`
        : `${who} added ${opts.itemCount} logs`;
  }
  return JSON.stringify({ title: opts.petName, body, url: `/log?pet=${opts.petId}` });
}
```

import { eq } from "drizzle-orm";
import type { DrizzleD1Database } from "drizzle-orm/d1";
import { pushSubscriptions } from "../../db/schema";
import type { Env } from "../../env";
import { sendPush } from "../../lib/webpush";

export type SendableSubscription = {
  id: string;
  endpoint: string;
  p256dh: string;
  auth: string;
};

export type SendOutcome = "sent" | "deleted" | "failed";

/**
 * Send one push and self-heal dead endpoints.
 *  - 2xx → "sent"
 *  - 403 (VAPID mismatch after key rotation) / 404 / 410 (endpoint gone) →
 *    delete the subscription, "deleted"
 *  - anything else / network error → "failed" (left for a later retry)
 */
export async function sendOneAndCleanup(
  db: DrizzleD1Database,
  env: Env,
  sub: SendableSubscription,
  payload: string,
): Promise<SendOutcome> {
  let status: number;
  try {
    status = await sendPush(
      { endpoint: sub.endpoint, p256dh: sub.p256dh, auth: sub.auth },
      payload,
      env,
    );
  } catch {
    return "failed";
  }
  if (status === 403 || status === 404 || status === 410) {
    await db.delete(pushSubscriptions).where(eq(pushSubscriptions.id, sub.id));
    return "deleted";
  }
  return status >= 200 && status < 300 ? "sent" : "failed";
}
```

- [ ] **Step 1: Create the DO with the `ping`/`alarm` skeleton + helper**

Create `worker/src/domain/push/careteam-notifier.ts`:

```ts
import { DurableObject } from "cloudflare:workers";
import type { Category } from "@pawary/shared";
import { and, asc, eq, gt, isNull } from "drizzle-orm";
import { drizzle } from "drizzle-orm/d1";
import {
  activities,
  petMembers,
  pets,
  pushSubscriptions,
  users,
} from "../../db/schema";
import type { Env } from "../../env";
import { buildNewLogPayload } from "./new-log";
import { sendOneAndCleanup } from "./send";

/** Fixed coalescing window from the first un-notified add. */
const WINDOW_MS = 60_000;
/** Per-alarm fan-out safety cap. */
const MAX_SENDS = 500;

/**
 * One instance per pet (idFromName(petId)). Debounces new-activity pings into a
 * single coalesced push per recipient. State: a `lastNotifiedAt` watermark and
 * the `petId`; the alarm queries D1 for everything created since the watermark.
 */
export class CareteamNotifier extends DurableObject<Env> {
  /** Called from the activity-create handler. Arms a single fixed-window alarm. */
  async ping(petId: string): Promise<void> {
    await this.ctx.storage.put("petId", petId);
    const pending = await this.ctx.storage.getAlarm();
    if (pending !== null) return; // fixed window — don't reset
    const now = Date.now();
    if ((await this.ctx.storage.get<number>("lastNotifiedAt")) === undefined) {
      // First arm on a fresh DO: look back one window so we notify only recent
      // activity (including the add that triggered this ping), never history.
      await this.ctx.storage.put("lastNotifiedAt", now - WINDOW_MS);
    }
    await this.ctx.storage.setAlarm(now + WINDOW_MS);
  }

  async alarm(): Promise<void> {
    const petId = await this.ctx.storage.get<string>("petId");
    if (!petId) return;
    const db = drizzle(this.env.DB);
    const watermark = (await this.ctx.storage.get<number>("lastNotifiedAt")) ?? 0;

    const rows = await db
      .select({
        createdAt: activities.createdAt,
        createdBy: activities.createdBy,
        category: activities.category,
        authorName: users.displayName,
      })
      .from(activities)
      .innerJoin(users, eq(users.id, activities.createdBy))
      .where(
        and(
          eq(activities.petId, petId),
          gt(activities.createdAt, watermark),
          isNull(activities.deletedAt),
        ),
      )
      .orderBy(asc(activities.createdAt))
      .all();

    if (rows.length === 0) return; // nothing new; watermark unchanged
    const maxCreatedAt = rows[rows.length - 1].createdAt;

    const pet = await db
      .select({ name: pets.name })
      .from(pets)
      .where(eq(pets.id, petId))
      .get();
    if (!pet) {
      await this.ctx.storage.put("lastNotifiedAt", maxCreatedAt);
      return;
    }

    // Recipients: members of this pet who opted in and have a subscription.
    // One row per (member × subscription). Authors are filtered per-recipient.
    const recipients = await db
      .select({
        userId: petMembers.userId,
        locale: users.locale,
        subId: pushSubscriptions.id,
        endpoint: pushSubscriptions.endpoint,
        p256dh: pushSubscriptions.p256dh,
        auth: pushSubscriptions.auth,
      })
      .from(petMembers)
      .innerJoin(users, eq(users.id, petMembers.userId))
      .innerJoin(pushSubscriptions, eq(pushSubscriptions.userId, petMembers.userId))
      .where(and(eq(petMembers.petId, petId), eq(users.notifyCareteamLogs, true)))
      .all();

    const payloadByUser = new Map<string, string | null>();
    let sends = 0;
    for (const r of recipients) {
      if (sends >= MAX_SENDS) break;
      let payload = payloadByUser.get(r.userId);
      if (payload === undefined) {
        const items = rows.filter((row) => row.createdBy !== r.userId);
        if (items.length === 0) {
          payloadByUser.set(r.userId, null);
          payload = null;
        } else {
          const authorNames = [
            ...new Map(items.map((row) => [row.createdBy, row.authorName])).values(),
          ];
          const category: Category | null =
            items.length === 1 ? items[0].category : null;
          payload = buildNewLogPayload({
            petName: pet.name,
            petId,
            authorNames,
            itemCount: items.length,
            category,
            locale: r.locale,
          });
          payloadByUser.set(r.userId, payload);
        }
      }
      if (!payload) continue;
      sends++;
      await sendOneAndCleanup(
        db,
        this.env,
        { id: r.subId, endpoint: r.endpoint, p256dh: r.p256dh, auth: r.auth },
        payload,
      );
    }

    // Advance after the send attempt (idempotent on alarm retry).
    await this.ctx.storage.put("lastNotifiedAt", maxCreatedAt);
  }
}

/** Fire-and-forget arm of the per-pet notifier. */
export async function pingCareteamNotifier(env: Env, petId: string): Promise<void> {
  const id = env.CARETEAM_NOTIFIER.idFromName(petId);
  await env.CARETEAM_NOTIFIER.get(id).ping(petId);
}
```

## Self-Review Notes (for the implementer)

- **Watermark correctness:** the DO never queries the pet's full history — on a
  fresh DO `lastNotifiedAt` is seeded to `now - 60s` on the first ping (Task 7),
  and advances to the newest `createdAt` after every fire.
- **Idempotency:** alarms retry on thrown exceptions; the watermark advances
  after the send attempt, so a retry re-queries from the new watermark and
  re-notifies nothing (Task 8 covers this).
- **Author exclusion is per-recipient** (Task 7/8): a member never gets pushed
  about their own log even when others logged in the same window.
- **Refactor safety:** Task 6 is behaviour-preserving; `push-cron.test.ts` is
  the guard. Do not change cron semantics.
- **Config drift:** the DO binding + migration must exist in all three env
  blocks of `wrangler.jsonc` (top-level, production, preview) — miniflare reads
  the top-level for tests; production/preview need their own copies.
