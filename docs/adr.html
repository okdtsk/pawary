Pawary — Architecture Decision Records

A running log of significant technical decisions, so humans can review why the system is the way it is. Newest first.

How to add a decision: append one object to the ADRS array below (in docs/adr.html) when a PR makes a notable architectural choice. Keep the highest id + 1, set status to accepted/proposed, and fill context / decision / consequences. When a later decision replaces an earlier one, set the old entry's status to superseded and its supersededBy to the new id. See CLAUDE.md and docs/development-workflow.md.
